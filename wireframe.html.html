HTML 직접 Cafe24 위젯에 동일 형태 없음. HTML 고급편집으로 직접 구성. 검정 배경으로 시선 분리. B2B 클릭 유도 핵심.
SECTION 5 · PRODUCT GRID
위젯 상품진열 위젯(탭형). BEST 1·2 강제고정은 진열관리에서 설정. 5열 → 모바일 2열 자동 분기.
SECTION 6 · PROMOTIONS
하이브리드 이미지배너 위젯(2-1 분할). 좌측 메인은 텍스트 오버레이로 HTML 약간 수정. 우측 서브 2개는 링크배너.
SECTION 7 · STORY CARDS
HTML 직접 3개 카드. 위젯 미지원. 협동조합 신뢰도·ZAFERA 브랜드·탈종속 선언 — 소스랩 정체성 핵심 영역.
SECTION 8 · REVIEWS
위젯 Cafe24 기본 리뷰 위젯 또는 외부 앱(크리마 등) 연동. 4개 노출. 더보기 클릭 시 전체 리뷰 페이지로.
